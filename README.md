# L9110S Motor Control Library for Raspberry Pi

Библиотека для управления моторами через драйвер L9110S на Raspberry Pi. Позволяет контролировать скорость и направление каждого мотора по отдельности или матрицей.
Драйверов может быть сколько угодно, лишь бы пиннов хватило

## Быстрый старт

```python
from motor_control import Motor

# Создаём мотор на пинах 17 (DIR) и 18 (PWM)
motor = Motor(17, 18)

# Едем вперёд на 70% мощности
motor.on(70)

# Едем назад на 50% мощности
motor.on(-50)

# Останавливаем мотор
motor.off()

# Управление сразу четыремя моторами по матрице. Может быть удобно для управления mecanum-колесами
# Передаем список четырех инициализированных моторов
motors = [motor_a, motor_b, motor_c, motor_d]  # [передний_левый, передний_правый, задний_левый, задний_правый]

Motor.matrix(motors, [[100, 100],  # Передний левый и правый
                      [100, 100]]) # Задний левый и правый
